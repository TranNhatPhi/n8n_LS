Trạm 1: Tiếp Nhận & Khớp File

Kiểm Tra File Đơn Hàng & Liên Kết SOForm Theo Account

🎯 Mục tiêu & Điều kiện đầu vào

Hệ thống đọc danh sách đơn hàng. Mỗi dòng có trường Account (ví dụ H040M, K413M). Hệ thống tìm trong danh sách các file SOForm đã tải lên file nào có tên chứa mã Account này. Nếu không tìm thấy file SOForm tương ứng, dòng đơn hàng lập tức chuyển sang trạng thái REVIEW với lý do "Không có SOF cho account", tuyệt đối không dùng SOF của khách khác.

Quy tắc an toàn: Không bao giờ sửa file đơn hàng gốc. Đơn hàng Word/PDF được chuyển đổi thành bảng dữ liệu trung gian chuẩn trước khi kiểm tra.

BƯỚC 5: KIẾN TRÚC HỆ THỐNG N8N + DOCKER WORKER

Mô Hình Triển Khai An Toàn Trên MacBook

Giải thích cách n8n và Docker worker cô lập bảo mật, không rò rỉ dữ liệu

n8n Workflow Hub

Cung cấp Webhook / Form tải file cho người dùng. Đóng gói các file SOF và file đơn hàng, đẩy sang Docker network nội bộ. Cổng worker không mở ra ngoài MacBook, đảm bảo an toàn mạng.

Worker Cô Lập & Tự Thu Dọn

Chạy Python, OpenPyXL, python-docx, PyMuPDF trong container cô lập. Không bao giờ sửa file đơn hàng gốc. Tự động xóa file tạm sau khi hoàn tất.

DeepSeek AI Kiểm Tra Bằng Chứng

Chỉ kích hoạt khi không có rule cứng. Kết quả của AI vẫn phải trải qua bộ lọc xác minh tọa độ ô (cell range) và trích dẫn nguyên văn trước khi được chấp thuận.
